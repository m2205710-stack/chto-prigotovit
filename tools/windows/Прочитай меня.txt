«Что приготовить?» — подбор блюд из продуктов, которые есть дома

КАК ЗАПУСТИТЬ
1. Распакуйте архив целиком в любую папку (например, на Рабочий стол).
2. Откройте папку «Что приготовить» и дважды щёлкните файл «Что приготовить.exe».
   Устанавливать Python не нужно — он уже встроен в папку «runtime».

ЕСЛИ WINDOWS ПРЕДУПРЕЖДАЕТ «Windows защитил ваш компьютер»
Так бывает с любыми программами, скачанными из интернета, у которых нет платной
цифровой подписи. Нажмите «Подробнее», затем «Выполнить в любом случае».

ЧТО ВНУТРИ
  Что приготовить.exe     — запуск приложения
  Проверка ТЗ.exe         — автоматическая проверка требований ТЗ
  app\                    — программа на Python (исходный код, база данных, значки, картинки блюд)
  runtime\                — встроенный Python 3.12 и библиотека интерфейса PySide6
